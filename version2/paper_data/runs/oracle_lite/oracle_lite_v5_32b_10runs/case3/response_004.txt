[UNDERSPECIFICATION 1] Diphoton system reuse in pT and mass

Original phrase:
"Use this same diphoton system to compute diphoton pT."

Why this matters:
The phrase implies that the diphoton system defined by the leading and subleading photons should be reused for computing diphoton pT. However, it is not explicitly stated whether the diphoton system is a fixed object (e.g., stored as a composite object) or if the pT is computed on-the-fly using the same pair of photons. This can lead to different implementations, especially if later steps modify the photon collection.

Question to user:
Should the diphoton system be stored as a fixed composite object for all subsequent calculations, or should the diphoton pT be computed dynamically using the same pair of photons each time?

Golden axe:
Store the diphoton system as a fixed composite object for all subsequent calculations.

Silver axe:
Compute the diphoton pT dynamically using the same pair of photons each time.

Recommended default:
Golden axe
