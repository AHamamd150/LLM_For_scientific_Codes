[UNDERSPECIFICATION 1] z_obj reuse and definition

Original phrase:
"Build z_obj from the two selected electrons using summed four-momentum."

Why this matters:
The phrase does not clarify whether z_obj is a temporary object used only for the invariant mass cut, or if it is a persistent object that will be used in later steps (e.g., for plotting the pT of z_obj or for angular separation with MET). This affects whether and how the object is stored and reused.

Question to user:
Is z_obj meant to be a persistent object used in multiple plots and selections, or is it only used temporarily for the invariant mass cut?

Golden axe:
z_obj is built and retained for all plots and further selections.

Silver axe:
z_obj is built only for the invariant mass cut and not stored for later use.

Recommended default:
Golden axe
