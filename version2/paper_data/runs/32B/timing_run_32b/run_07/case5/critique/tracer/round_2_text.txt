  - structure: single-constituent

* leading tau pT

  - upstream chain: tau1 = helper_get_leading(taus)
  - collection definition: taus = [t for t in get_taus(event) if t['pt'] > 20 and abs(t['eta']) < 2.3]
  - structure: single-constituent

* subleading tau pT
  - computed/defined as: tau2['pt']
  - upstream chain: tau2 = helper_get_subleading(taus)
  - collection definition: taus = [t for t in get_taus(event) if t['pt'] > 20 and abs(t['eta']) < 2.3]
  - structure: single-constituent

* leading jet pT

  - structure: single-constituent

* subleading jet pT
  - computed/defined as: jet2['pt']
  - upstream chain: jet2 = helper_get_subleading(jets)
  - collection definition: jets = [j for j in get_jets(event) if j['pt'] > 30 and abs(j['eta']) < 4.7]
  - structure: single-constituent

* delta R between taus
  - computed/defined as: helper_delta_r(tau1, tau2)
  - upstream chain: helper_delta_r -> math.sqrt(deta**2 + dphi**2)
  - collection definition: tau1 = helper_get_leading(taus), tau2 = helper_get_subleading(taus)
  - structure: composite-derived

* delta phi between ditau and dijet
  - computed/defined as: helper_delta_phi(ditau_obj['phi'], dijet_obj['phi'])
  - upstream chain: helper_delta_phi -> phi1 - phi2 normalized to [-π, π]
  - collection definition: ditau_obj = sum_objects(tau1, tau2), dijet_obj = sum_objects(jet1, jet2)
  - structure: composite-derived

* centrality between jets and ditau
  - computed/defined as: centrality_between_jets(ditau_obj, jet1, jet2)
  - upstream chain: centrality_between_jets -> min(abs(dphi1), abs(dphi2)) / math.pi
  - collection definition: ditau_obj = sum_objects(tau1, tau2), jet1 = helper_get_leading(jets), jet2 = helper_get_subleading(jets)
  - structure: composite-derived

* b-tagged jets
  - computed/defined as: get_bjets(event)
  - upstream chain: get_bjets(event) -> [o for o in event['objects'] if o['type'] == 4 and int(o['btag']) == 1]
  - collection definition: o['type'] == 4 and int(o['btag']) == 1
  - structure: single-constituent

* cutflow counters
  - computed/defined as: cutflow dictionary with counters
  - upstream chain: cutflow = {"initial": len(all_events), "2_taus": 0, ...}
  - collection definition: events processed through selection steps
  - structure: multi-input
