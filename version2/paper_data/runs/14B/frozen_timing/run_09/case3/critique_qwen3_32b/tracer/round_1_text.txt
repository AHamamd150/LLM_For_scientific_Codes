* photons_selected
  - computed/defined as: [p for p in photons if p['pt'] > 25 and abs(p['eta']) < 2.37]
  - upstream chain: photons, p['pt'], p['eta']
  - collection definition: p['pt'] > 25 and abs(p['eta']) < 2.37
  - structure: multi-input

* photons_clean
  - computed/defined as: [p for p in photons_selected if not (1.37 < abs(p['eta']) < 1.52)]
  - upstream chain: photons_selected, p['eta']
  - collection definition: not (1.37 < abs(p['eta']) < 1.52)
  - structure: multi-input

* leading_photon
  - computed/defined as: helper_get_leading(photons_clean)
  - upstream chain: photons_clean
  - collection definition: sorted by p['pt'] in descending order, first element
  - structure: single-constituent

* subleading_photon
  - computed/defined as: helper_get_subleading(photons_clean)
  - upstream chain: photons_clean
  - collection definition: sorted by p['pt'] in descending order, second element
  - structure: single-constituent

* diphoton
  - computed/defined as: sum_objects(leading_photon, subleading_photon)
  - upstream chain: leading_photon, subleading_photon
  - collection definition: sum of four-momenta of leading_photon and subleading_photon
  - structure: composite-derived

* m_gammagamma
  - computed/defined as: diphoton['mass'] if diphoton else 0.0
  - upstream chain: diphoton
  - collection definition: invariant mass of diphoton system
  - structure: composite-derived

* pt_diphoton
  - computed/defined as: diphoton['pt'] if diphoton else 0.0
  - upstream chain: diphoton
  - collection definition: transverse momentum of diphoton system
  - structure: composite-derived

* dr_photons
  - computed/defined as: helper_delta_r(leading_photon, subleading_photon)
  - upstream chain: leading_photon, subleading_photon
  - collection definition: sqrt((eta1 - eta2)^2 + (delta_phi(phi1, phi2))^2)

  - upstream chain: leading_photon['phi'], subleading_photon['phi']
  - collection definition: normalized difference in phi between leading and subleading photons
  - structure: multi-input
