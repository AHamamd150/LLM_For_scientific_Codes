# Physics Process: p p > H, H > gamma gamma
# ==========================================

[SELECTION_CUTS]
- Select photons with pT > 25 GeV and |eta| < 2.37.
- Exclude photons in the crack region 1.37 < |eta| < 1.52.
- Require at least 2 photons
- Define the leading photon and subleading photon after photon selection.
- Leading photon pT > 35 GeV
- Subleading photon pT > 25 GeV
- Build the diphoton system from the leading photon and the subleading photon.
- Define m_gammagamma as the invariant mass of this diphoton system.
- Use this same diphoton system to compute diphoton pT.
- Select diphoton invariant mass between 105 and 160 GeV.
- Select leading photon pT / m_gammagamma > 0.35.
- Select subleading photon pT / m_gammagamma > 0.25.

Apply the above cuts sequentially and skip the event immediately when a cut is not satisfied.
Increment each cutflow counter immediately after its cut is passed.


[PLOTS_FOR_VALIDATION]
- Plot the following as histograms:
1 Plot diphoton invariant mass in the range 100 to 160 GeV
2 Plot pT of the leading photon
3 Plot pT of the subleading photon
4 Plot pT of the diphoton system
5 Plot eta of the leading photon
6 Plot eta of the subleading photon
7 Plot delta R between the two photons
8 Plot delta phi between the two photons
9 Plot the |cos(theta*)| of the diphoton system in Collins-Soper frame

Use simple validation histograms.
For each histogram: plt.figure(); plt.hist(values, bins=40, density=True); plt.xlabel(...); plt.ylabel("density"); plt.savefig(...); plt.close().
Use concrete short ASCII labels and filenames.


[OUTPUT_STRUCTURE]
- After the event loop, print one cutflow summary with the number of events after each selection step.
- save the figures in png format
- Save to CSV for MLP analysis:
  1- Diphoton invariant mass
  2- Leading photon pT
  3- Subleading photon pT
  4- Delta R between photons
  5- pT of diphoton system
  6- |cos(theta*)|
