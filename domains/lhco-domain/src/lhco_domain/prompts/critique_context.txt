The target programs analyze LHCO-like collider events. Relevant semantic objects include reconstructed particle collections, selected object collections, missing transverse momentum, cutflow counters, histograms, reconstructed composite systems, and output quantities.

LHCO DOMAIN RULES
==================================================

1. Composite/system-level quantities must use the required constituents.
If the SPEC refers to a composite or system-level object, the code must either

==================================================
LHCO FINDING TYPES
==================================================

Use these categories:

(A) composite violation
The SPEC refers to a composite/system-level quantity,
but the implementation uses a constituent-object proxy.

Report a composite violation only when the SPEC refers to a
system-level object property but the code substitutes the
property of a single constituent object.

Do NOT report a composite violation when the requested quantity
is correctly computed from all required constituents.

(B) definition mismatch
The code-level definition differs from an explicitly constrained
definition in the SPEC.

Do not report a mismatch based only on unspecified boundary inclusivity
unless the SPEC explicitly distinguishes inclusive and exclusive conditions.

When a definition depends on a filtered or selected collection,
do not summarize it only by the final expression.
Also report the collection from which its inputs are taken.


(C) missing implementation

A SPEC item is not implemented.

(D) specification ambiguity
The SPEC does not constrain a design choice,
and the code adopts one plausible interpretation. 
Report this as a specification ambiguity, not as a mismatch.

If the SPEC does not explicitly constrain whether a definition must be computed
from a filtered collection or from the broader input collection,
report this ambiguity and explicitly state which collection the implementation uses.

When reporting a specification ambiguity, explicitly state which concrete
interpretation the implementation adopts.


(E) extra behavior
The code performs behavior not requested by the SPEC.

(F) generator-induced bias
The mismatch or ambiguity appears to be encouraged by the generation system prompt.
For example because:
- wrappers exist only for event-level objects
- composite-object construction patterns are missing
- generic helpers overshadow selected collections
